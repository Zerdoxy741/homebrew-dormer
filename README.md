# Dormer pour Homebrew

```
brew install --cask zerdoxy741/dormer/dormer
```

Dormer n'est pas notarisé par Apple : macOS affiche un avertissement la première fois que tu l'ouvres. Va dans Réglages Système › Confidentialité et sécurité et clique sur « Ouvrir quand même ». Homebrew vérifie l'empreinte SHA-256 du fichier téléchargé ; elle est aussi publiée sur [dormernotch.com/fr/versions](https://dormernotch.com/fr/versions/).

Dormer se met à jour tout seul. Pour le désinstaller : `brew uninstall --cask dormer` (ajoute `--zap` pour effacer aussi ses réglages).

---
